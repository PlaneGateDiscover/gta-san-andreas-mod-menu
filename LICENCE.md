## 🧩 About

**GTA San Andreas Companion** is a curated list of GTA San Andreas open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, waypoint switcher
- **Quality-of-Life Helpers** — vehicle catalog, weapon manager, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Waypoint Switcher — practice from any mission checkpoint
- Show Hitboxes — visualize collision hitboxes
- Replay Notes — record and review mission runs
- Playback Speed — adjust mission playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Vehicle Catalog — browse cars, bikes, planes, boats
- Custom Skin Notes — organize player outfits and tattoos
- Solid overlay Trail — improved overlay visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any mission
- Weather Control — manually switch weather mid-game
- Jump Buffer Notes — chain complex stunts in the editor
